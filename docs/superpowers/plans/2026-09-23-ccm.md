# ccm Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Binario `ccm` que abre un popup de tmux (`C-g`) listando los panes con Claude Code, su estado, y permite saltar/filtrar/reordenar/ocultar con teclas estilo vim.

**Architecture:** Un binario Go con 3 subcomandos: `ccm` (TUI Bubble Tea), `ccm hook <evento>` (lo llaman los hooks de Claude Code y escribe un JSON de estado por pane) y `ccm seen` (lo llaman hooks de tmux; marca `done → idle`). La TUI cruza `tmux list-panes` con esos JSON, lee títulos de los transcripts y aplica el orden persistido en `order.json`. Paquetes chicos bajo `internal/`, tmux detrás de una interfaz con fake.

**Tech Stack:** Go 1.24, `github.com/charmbracelet/bubbletea` (v1), `github.com/charmbracelet/lipgloss`, `github.com/sahilm/fuzzy`, `github.com/mattn/go-runewidth`.

**Spec:** `docs/superpowers/specs/2026-09-23-ccm-design.md`

## Global Constraints

- Módulo Go: `ccm`. Go 1.24 (instalado: go1.24.10).
- Dependencias externas: solo bubbletea v1, lipgloss, sahilm/fuzzy, go-runewidth.
- `ccm hook` nunca escribe a stdout ni a stderr y siempre sale con código 0. Errores a `$XDG_CACHE_HOME/ccm/log`.
- Rutas: `$XDG_CACHE_HOME/ccm/panes/<pane_id sin %>.json`, `$XDG_CACHE_HOME/ccm/titles/`, `$XDG_CACHE_HOME/ccm/log`, `$XDG_STATE_HOME/ccm/order.json`; defaults `~/.cache` y `~/.local/state`.
- Binario instalado en `$HOME/go/bin/ccm` (`go install ./cmd/ccm`).
- Keybind del popup: `C-g` (tabla root). Popup `-h "60%" -w "80%"`.
- Colores (tokyonight): waiting `#f7768e`, working `#e0af68`, done `#9ece6a`, idle `#565f89`, unknown `#3b4261`, acento `#7aa2f7`.
- Textos de UI en español.
- En shell, tmux siempre como `/usr/bin/tmux` (el `tmux` pelado es un alias de zsh que falla fuera de shells interactivos). En Go, vía `tmux.Find()`.
- Commits: mensaje corto en español + línea `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

**Desvíos menores respecto de la spec (decididos en el plan):**
- El caché de títulos guarda por `session_id` el offset leído + los tres títulos (superset de "cachear el primer `ai-title`"): así ni al arrancar ni en cada refresco se reescanea el transcript entero, solo los bytes nuevos. El cambio se detecta por tamaño (los transcripts son append-only); si el archivo se achica, se reescanea desde 0.
- En la zona de detalle el estado se muestra con etiqueta en español (`esperando input`, `trabajando`, `terminó`, `idle`, `desconocido`).

## Review Focus

1. Transcript a medio escribir (última línea sin `\n` mientras CC escribe): no se consume ni rompe títulos; se lee cuando se completa. → test en Task 5.
2. Dos CC en panes distintos de la misma window y mismo cwd: dos entradas con claves distintas. → test en Task 7.
3. Nombres de sesión con espacios, puntos o que son prefijo de otra sesión (`a` vs `a2w`): se parsean bien y el salto usa targets exactos (`=sesión`). → tests en Task 3.
4. Títulos/carpetas largos o con caracteres anchos en un popup angosto: ninguna línea supera el ancho. → test en Task 10.
5. `ccm hook` con stdin vacío o JSON roto, sin `TMUX_PANE`, evento desconocido o sin evento: stdout y stderr vacíos, exit 0. → test en Task 11.

// Package fsutil tiene helpers de filesystem.
package fsutil

import (
	"os"
	"path/filepath"
)

// WriteFileAtomic escribe a un temporal en el mismo directorio y lo renombra,
// así un lector concurrente nunca ve el archivo a medio escribir.
func WriteFileAtomic(path string, data []byte) error {
	dir := filepath.Dir(path)
	if err := os.MkdirAll(dir, 0o755); err != nil {
		return err
	}
	f, err := os.CreateTemp(dir, ".tmp-*")
	if err != nil {
		return err
	}
	tmp := f.Name()
	if _, err := f.Write(data); err != nil {
		f.Close()
		os.Remove(tmp)
		return err
	}
	if err := f.Close(); err != nil {
		os.Remove(tmp)
		return err
	}
	if err := os.Rename(tmp, path); err != nil {
		os.Remove(tmp)
		return err
	}
	return nil
}
```

// Package state guarda el estado de cada sesión de Claude Code, un archivo
// JSON por pane de tmux.
package state

import (
	"encoding/json"
	"errors"
	"io/fs"
	"os"
	"path/filepath"
	"strings"
	"time"

	"ccm/internal/fsutil"
)

type State string

const (
	Idle    State = "idle"
	Working State = "working"
	Waiting State = "waiting"
	Done    State = "done"
	Unknown State = "unknown"
)

type Pane struct {
	PaneID         string    `json:"pane_id"`
	SessionID      string    `json:"session_id"`
	Cwd            string    `json:"cwd"`
	TranscriptPath string    `json:"transcript_path"`
	State          State     `json:"state"`
	Since          time.Time `json:"since"`
}

// Apply devuelve p con el estado st. Since solo se mueve si el estado cambia.
func Apply(p Pane, st State, now time.Time) Pane {
	if p.State != st {
		p.State = st
		p.Since = now.UTC()
	}
	return p
}

type Store struct{ Dir string }

// "%41" -> "41.json"
func fileName(paneID string) string { return strings.TrimPrefix(paneID, "%") + ".json" }

func (s Store) path(paneID string) string { return filepath.Join(s.Dir, fileName(paneID)) }

func (s Store) Load(paneID string) (Pane, error) {
	b, err := os.ReadFile(s.path(paneID))
	if err != nil {
		return Pane{}, err
	}
	var p Pane
	if err := json.Unmarshal(b, &p); err != nil {
		return Pane{}, err
	}
	return p, nil
}

func (s Store) Save(p Pane) error {
	b, err := json.MarshalIndent(p, "", "  ")
	if err != nil {
		return err
	}
	return fsutil.WriteFileAtomic(s.path(p.PaneID), b)
}

func (s Store) Delete(paneID string) error {
	err := os.Remove(s.path(paneID))
	if errors.Is(err, fs.ErrNotExist) {
		return nil
	}
	return err
}

// All devuelve los estados válidos indexados por pane id. Archivos corruptos
// o temporales se ignoran: esos panes se verán como Unknown.
func (s Store) All() (map[string]Pane, error) {
	out := map[string]Pane{}
	ents, err := os.ReadDir(s.Dir)
	if errors.Is(err, fs.ErrNotExist) {
		return out, nil
	}
	if err != nil {
		return nil, err
	}
	for _, e := range ents {
		if e.IsDir() || !strings.HasSuffix(e.Name(), ".json") {
			continue
		}
		b, err := os.ReadFile(filepath.Join(s.Dir, e.Name()))
		if err != nil {
			continue
		}
		var p Pane
		if json.Unmarshal(b, &p) != nil || p.PaneID == "" {
			continue
		}
		out[p.PaneID] = p
	}
	return out, nil
}
```

```go
// Package tmux habla con el server de tmux. Todo pasa por la interfaz Client
// para poder testear el resto con Fake.
package tmux

import (
	"bytes"
	"errors"
	"fmt"
	"os"
	"os/exec"
	"strconv"
	"strings"
)

type PaneInfo struct {
	PaneID          string
	Session         string
	Window          int
	Pane            int
	Command         string
	Path            string
	WindowActive    bool
	SessionAttached bool
}

type Client interface {
	ListPanes() ([]PaneInfo, error)
	PaneActive(paneID string) (bool, error)
	Switch(p PaneInfo) error
}

// Tab como separador: los nombres de sesión pueden tener espacios.
const listFormat = "#{pane_id}\t#{session_name}\t#{window_index}\t#{pane_index}\t" +
	"#{pane_current_command}\t#{pane_current_path}\t#{window_active}\t#{session_attached}"

func ParsePanes(out string) ([]PaneInfo, error) {
	var ps []PaneInfo
	for _, line := range strings.Split(strings.TrimRight(out, "\n"), "\n") {
		if line == "" {
			continue
		}
		f := strings.Split(line, "\t")
		if len(f) != 8 {
			return nil, fmt.Errorf("línea de list-panes inesperada: %q", line)
		}
		w, err := strconv.Atoi(f[2])
		if err != nil {
			return nil, err
		}
		p, err := strconv.Atoi(f[3])
		if err != nil {
			return nil, err
		}
		ps = append(ps, PaneInfo{
			PaneID: f[0], Session: f[1], Window: w, Pane: p,
			Command: f[4], Path: f[5],
			WindowActive:    f[6] == "1",
			SessionAttached: f[7] != "" && f[7] != "0",
		})
	}
	return ps, nil
}

// Find busca el binario de tmux. En la Mac suele estar en /opt/homebrew/bin,
// que puede no estar en el PATH de un hook.
func Find() (string, error) {
	if p, err := exec.LookPath("tmux"); err == nil {
		return p, nil
	}
	for _, p := range []string{"/usr/bin/tmux", "/opt/homebrew/bin/tmux", "/usr/local/bin/tmux"} {
		if _, err := os.Stat(p); err == nil {
			return p, nil
		}

type Exec struct {
	Bin    string
	Socket string
}

func (e Exec) run(args ...string) (string, error) {
	if e.Socket != "" {
		args = append([]string{"-L", e.Socket}, args...)
	}
	cmd := exec.Command(e.Bin, args...)
	var stderr bytes.Buffer
	cmd.Stderr = &stderr
	out, err := cmd.Output()
	if err != nil {
		return "", fmt.Errorf("tmux %s: %w: %s", strings.Join(args, " "), err, strings.TrimSpace(stderr.String()))
	}
	return string(out), nil
}

func (e Exec) ListPanes() ([]PaneInfo, error) {
	out, err := e.run("list-panes", "-a", "-F", listFormat)
	if err != nil {
		return nil, err
	}
	return ParsePanes(out)

// PaneActive: la window del pane es la activa de su sesión y la sesión tiene
// algún cliente attached, o sea, lo estás mirando.
func (e Exec) PaneActive(paneID string) (bool, error) {

	if err != nil {
		return false, err

// Package hook traduce eventos de Claude Code (y de tmux) a cambios de estado.
package hook

import (
	"encoding/json"
	"errors"
	"fmt"
	"io"
	"strings"
	"time"

	"ccm/internal/state"
	"ccm/internal/tmux"
)

// Input son los campos que usamos del JSON que Claude Code manda por stdin.
type Input struct {
	SessionID      string `json:"session_id"`
	TranscriptPath string `json:"transcript_path"`
	Cwd            string `json:"cwd"`
	Prompt         string `json:"prompt"`
}

type Deps struct {
	Store      state.Store
	PaneID     string
	Now        func() time.Time
	PaneActive func(paneID string) (bool, error)
}

var ErrUnknownEvent = errors.New("evento desconocido")

func Run(event string, stdin io.Reader, d Deps) error {
	if d.PaneID == "" {
		return nil // claude fuera de tmux: no hay a qué pane asociarlo
	}
	var in Input
	if b, err := io.ReadAll(stdin); err == nil && len(b) > 0 {
		_ = json.Unmarshal(b, &in) // stdin roto: igual registramos la transición
	}

	var target state.State
	switch event {
	case "end":
		return d.Store.Delete(d.PaneID)
	case "start":
		target = state.Idle
	case "prompt":
		if injected(in.Prompt) {
			return nil
		}
		target = state.Working
	case "ask", "permission":
		target = state.Waiting
	case "tool-done":
		target = state.Working
	case "stop":
		target = state.Done
		if active, err := d.PaneActive(d.PaneID); err == nil && active {
			target = state.Idle // terminó mientras lo mirabas
		}
	default:
		return fmt.Errorf("%w: %q", ErrUnknownEvent, event)
	}

	p, err := d.Store.Load(d.PaneID)
	if err != nil {
		p = state.Pane{PaneID: d.PaneID}
	}
	if in.SessionID != "" {
		p.SessionID = in.SessionID
	}
	if in.Cwd != "" {
		p.Cwd = in.Cwd
	}
	if in.TranscriptPath != "" {
		p.TranscriptPath = in.TranscriptPath
	}
	return d.Store.Save(state.Apply(p, target, d.Now()))
}

// UserPromptSubmit también dispara cuando el harness inyecta un aviso como si
// fuera un prompt tuyo. Misma regla que notify.sh.
func injected(prompt string) bool {
	return strings.HasPrefix(prompt, "<task-notification>") ||
		strings.HasPrefix(prompt, "<system-reminder>")
}

// Seen pasa a idle los panes en done de toda window que estás mirando.
func Seen(c tmux.Client, s state.Store, now time.Time) error {
	panes, err := c.ListPanes()
	if err != nil {
		return err
	}
	for _, p := range panes {
		if !p.WindowActive || !p.SessionAttached {
			continue
		}
		st, err := s.Load(p.PaneID)
		if err != nil || st.State != state.Done {
			continue
		}
		if err := s.Save(state.Apply(st, state.Idle, now)); err != nil {
			return err
		}
	}
	return nil
}

// Package transcript saca los títulos de una sesión de su transcript JSONL.
package transcript

import (
	"bufio"
	"bytes"
	"encoding/json"
	"io"
	"os"
	"path/filepath"

	"ccm/internal/fsutil"
)

type Titles struct {
	AgentName    string `json:"agent_name"`
	FirstAITitle string `json:"first_ai_title"`
	LastAITitle  string `json:"last_ai_title"`
}

// Row es el título de la fila: el nombre de /rename si hay; si no, el primer
// título autogenerado (el que describe con qué arrancó la sesión).
func (t Titles) Row() string {
	if t.AgentName != "" {
		return t.AgentName
	}
	return t.FirstAITitle
}

var (
	markAI    = []byte(`"ai-title"`)
	markAgent = []byte(`"agent-name"`)
)

// Feed procesa una línea del transcript. El prefiltro por bytes evita
// decodificar JSON en el 99% de las líneas.
func (t *Titles) Feed(line []byte) {
	if !bytes.Contains(line, markAI) && !bytes.Contains(line, markAgent) {
		return
	}
	var e struct {
		Type      string `json:"type"`
		AITitle   string `json:"aiTitle"`
		AgentName string `json:"agentName"`
	}
	if json.Unmarshal(line, &e) != nil {
		return
	}
	switch e.Type {
	case "ai-title":
		if e.AITitle == "" {
			return
		}
		if t.FirstAITitle == "" {
			t.FirstAITitle = e.AITitle
		}
		t.LastAITitle = e.AITitle
	case "agent-name":
		if e.AgentName != "" {
			t.AgentName = e.AgentName
		}
	}
}

type entry struct {
	Path   string `json:"path"`
	Offset int64  `json:"offset"`
	Titles Titles `json:"titles"`
}

// Cache lee cada transcript de forma incremental: recuerda hasta qué byte
// leyó (en memoria y en disco) y solo procesa lo nuevo.
type Cache struct {
	Dir string
	mem map[string]entry
}

func NewCache(dir string) *Cache { return &Cache{Dir: dir, mem: map[string]entry{}} }

func (c *Cache) Get(sessionID, path string) Titles {
	if sessionID == "" || path == "" {
		return Titles{}
	}
	e, ok := c.mem[sessionID]
	if !ok {
		e = c.loadDisk(sessionID)
	}
	if e.Path != path {
		e = entry{Path: path}
	}
	fi, err := os.Stat(path)
	if err != nil {
		c.mem[sessionID] = e
		return e.Titles
	}
	if fi.Size() < e.Offset {
		e = entry{Path: path} // se reescribió: empezar de nuevo
	}
	if fi.Size() > e.Offset {
		if n, err := scan(path, e.Offset, &e.Titles); err == nil && n > 0 {
			e.Offset += n
			c.saveDisk(sessionID, e)
		}
	}
	c.mem[sessionID] = e
	return e.Titles
}

// scan alimenta las líneas completas desde off y devuelve los bytes
// consumidos. Una última línea sin \n (CC escribiendo) no se consume.
func scan(path string, off int64, t *Titles) (int64, error) {
	f, err := os.Open(path)
	if err != nil {
		return 0, err
	}
	defer f.Close()
	if _, err := f.Seek(off, io.SeekStart); err != nil {
		return 0, err
	}
	r := bufio.NewReaderSize(f, 64*1024)
	var n int64
	for {
		line, err := r.ReadBytes('\n')
		if err == io.EOF {
			return n, nil
		}
		if err != nil {
			return n, err
		}
		n += int64(len(line))
		t.Feed(line)
	}
}

func (c *Cache) diskPath(sessionID string) string {
	return filepath.Join(c.Dir, filepath.Base(sessionID)+".json")
}

func (c *Cache) loadDisk(sessionID string) entry {
	var e entry
	b, err := os.ReadFile(c.diskPath(sessionID))
	if err != nil || json.Unmarshal(b, &e) != nil {
		return entry{}
	}
	return e
}

func (c *Cache) saveDisk(sessionID string, e entry) {
	if b, err := json.Marshal(e); err == nil {
		_ = fsutil.WriteFileAtomic(c.diskPath(sessionID), b)
	}
}

// Package order persiste el orden manual de las entradas y cuáles están ocultas.
package order

import (
	"encoding/json"
	"errors"
	"fmt"
	"io/fs"
	"os"
	"slices"

	"ccm/internal/fsutil"
)

// Key identifica una entrada entre reinicios de tmux y /clear de CC.
// Si se renombra la sesión o se renumeran windows, la entrada va al final.
func Key(session string, window, pane int, cwd string) string {
	return fmt.Sprintf("%s:%d.%d|%s", session, window, pane, cwd)
}

type Store struct {
	Order  []string `json:"order"`
	Hidden []string `json:"hidden"`
}

func Load(path string) (*Store, error) {
	b, err := os.ReadFile(path)
	if errors.Is(err, fs.ErrNotExist) {
		return &Store{}, nil
	}
	if err != nil {
		return &Store{}, err
	}
	var s Store
	if err := json.Unmarshal(b, &s); err != nil {
		return &Store{}, fmt.Errorf("order.json corrupto: %w", err)
	}
	return &s, nil
}

func (s *Store) Save(path string) error {
	b, err := json.MarshalIndent(s, "", "  ")
	if err != nil {
		return err
	}
	return fsutil.WriteFileAtomic(path, b)
}

func (s *Store) hidden(k string) bool { return slices.Contains(s.Hidden, k) }

// Visible: primero las claves de Order que están vivas, después las vivas que
// Order no conoce (entradas nuevas), en el orden de live. Sin ocultas.
func (s *Store) Visible(live []string) []string {
	alive := make(map[string]bool, len(live))
	for _, k := range live {
		alive[k] = true
	}
	seen := map[string]bool{}
	var out []string
	for _, k := range s.Order {
		if alive[k] && !seen[k] && !s.hidden(k) {
			out = append(out, k)
			seen[k] = true
		}
	}
	for _, k := range live {
		if !seen[k] && !s.hidden(k) {
			out = append(out, k)
			seen[k] = true
		}
	}
	return out
}

// materialize agrega a Order las entradas nuevas en la posición en la que ya
// se ven, para que pegar "debajo de" una de ellas funcione.
func (s *Store) materialize(live []string) {
	for _, k := range live {
		if !s.hidden(k) && !slices.Contains(s.Order, k) {
			s.Order = append(s.Order, k)
		}
	}
}

func remove(xs []string, k string) []string {
	var out []string
	for _, x := range xs {
		if x != k {
			out = append(out, x)
		}
	}
	return out
}

func (s *Store) Hide(live []string, key string) {
	s.materialize(live)
	s.Order = remove(s.Order, key)
	if !s.hidden(key) {
		s.Hidden = append(s.Hidden, key)
	}
}

// Paste inserta key debajo (below) o arriba de anchor y la saca de ocultas.
// Sin anchor (o anchor desconocido) va al final.
func (s *Store) Paste(live []string, key, anchor string, below bool) {
	if key == "" {
		return
	}
	s.Hidden = remove(s.Hidden, key)
	s.materialize(live)
	s.Order = remove(s.Order, key)
	i := slices.Index(s.Order, anchor)
	switch {
	case anchor == "" || i < 0:
		s.Order = append(s.Order, key)
	case below:
		s.Order = slices.Insert(s.Order, i+1, key)
	default:
		s.Order = slices.Insert(s.Order, i, key)
	}
}

func (s *Store) RestoreAll(live []string) {
	s.materialize(live)
	for _, h := range s.Hidden {
		if !slices.Contains(s.Order, h) {
			s.Order = append(s.Order, h)
		}
	}
	s.Hidden = nil
}

// Package entries arma la lista de sesiones de Claude Code cruzando tmux con
// los archivos de estado y los títulos.
package entries

import (
	"path/filepath"
	"time"

	"ccm/internal/order"
	"ccm/internal/state"
	"ccm/internal/tmux"
	"ccm/internal/transcript"
)

type Entry struct {
	Key    string
	Pane   tmux.PaneInfo
	State  state.State
	Since  time.Time
	Folder string // basename del cwd
	Title  string // título de la fila
	Detail string // último ai-title, para la zona de detalle
	Num    int    // 1..N según el orden; 0 hasta Arrange
}

type TitleSource func(sessionID, path string) transcript.Titles

func Collect(panes []tmux.PaneInfo, states map[string]state.Pane, titles TitleSource) []Entry {
	var out []Entry
	for _, p := range panes {
		if p.Command != "claude" {
			continue
		}
		// La clave usa pane_current_path (no el cwd del estado) para que no
		// cambie cuando el pane pasa de unknown a tener estado.
		e := Entry{
			Key:    order.Key(p.Session, p.Window, p.Pane, p.Path),
			Pane:   p,
			State:  state.Unknown,
			Folder: filepath.Base(p.Path),
		}
		if st, ok := states[p.PaneID]; ok {
			e.State, e.Since = st.State, st.Since
			if st.Cwd != "" {
				e.Folder = filepath.Base(st.Cwd)
			}
			t := titles(st.SessionID, st.TranscriptPath)
			e.Title, e.Detail = t.Row(), t.LastAITitle
		}
		out = append(out, e)
	}
	return out
}

func Keys(es []Entry) []string {
	ks := make([]string, len(es))
	for i, e := range es {
		ks[i] = e.Key
	}
	return ks
}

func Arrange(all []Entry, keys []string) []Entry {
	byKey := make(map[string]Entry, len(all))
	for _, e := range all {
		byKey[e.Key] = e
	}
	out := make([]Entry, 0, len(keys))
	for _, k := range keys {
		e, ok := byKey[k]
		if !ok {
			continue
		}
		e.Num = len(out) + 1
		out = append(out, e)
	}
	return out
}

func Purge(s state.Store, panes []tmux.PaneInfo, states map[string]state.Pane) {
	alive := make(map[string]bool, len(panes))
	for _, p := range panes {
		alive[p.PaneID] = true
	}
	for id := range states {
		if !alive[id] {
			_ = s.Delete(id)
		}
	}
}

func indicator(st state.State, frame int) string {
	switch st {
	case state.Waiting:
		return colWaiting.Render("●")
	case state.Working:
		return colWorking.Render(spinnerFrames[frame%len(spinnerFrames)])
	case state.Done:
		return colDone.Render("✓")
	case state.Idle:
		return colIdle.Render("○")

	}

func stateLabel(st state.State) string {
	switch st {
	case state.Waiting:
		return "esperando input"
	case state.Working:
		return "trabajando"
	case state.Done:
		return "terminó"
	case state.Idle:
		return "idle"
	default:
		return "desconocido"
	}
}

func humanSince(d time.Duration) string {
	if d < 0 {
		d = 0
	}
	switch {
	case d < time.Minute:
		return fmt.Sprintf("hace %ds", int(d.Seconds()))
	case d < time.Hour:
		return fmt.Sprintf("hace %dm", int(d.Minutes()))
	case d < 24*time.Hour:
		return fmt.Sprintf("hace %dh", int(d.Hours()))
	default:
		return fmt.Sprintf("hace %dd", int(d.Hours()/24))
	}
}

// fit deja s en exactamente w columnas: trunca con … o rellena con espacios.
func fit(s string, w int) string {
	if w <= 0 {
		return ""
	}
	return runewidth.FillRight(runewidth.Truncate(s, w, "…"), w)

package tui

import "ccm/internal/entries"

// row es una línea de la lista: un encabezado de sesión (entry == -1) o una
// entrada (entry = índice en la lista mostrada).
type row struct {
	header string
	entry  int
}

// buildRows emite un encabezado cada vez que cambia la sesión respecto de la
// fila anterior; una sesión se repite si sus entradas no son contiguas.
func buildRows(es []entries.Entry) []row {
	var rows []row
	for i, e := range es {
		if i == 0 || e.Pane.Session != es[i-1].Pane.Session {
			rows = append(rows, row{header: e.Pane.Session, entry: -1})
		}
		rows = append(rows, row{entry: i})
	}
	return rows
}

func keyMsg(s string) tea.KeyMsg {
	switch s {

	case "down":

	}
	return tea.KeyMsg{Type: tea.KeyRunes, Runes: []rune(s)}

import (
	"sort"
	"strconv"
	"time"

	tea "github.com/charmbracelet/bubbletea"
	"github.com/sahilm/fuzzy"

	"ccm/internal/entries"
	"ccm/internal/order"
	"ccm/internal/tmux"
)

type Deps struct {
	Load      func() ([]entries.Entry, error)
	Order     *order.Store
	SaveOrder func() error
	Switch    func(tmux.PaneInfo) error
	Now       func() time.Time
}

type mode int

const (
	normal mode = iota
	filtering
)

const (
	refreshEvery = time.Second
	spinEvery    = 100 * time.Millisecond
	seqTimeout   = time.Second            // dd, gg
	digitTimeout = 300 * time.Millisecond // segundo dígito
)

type (
	tickMsg    struct{}
	spinMsg    struct{}
	timeoutMsg struct{ seq int }
)

type Model struct {
	d        Deps
	live     []entries.Entry // como vienen de Load
	list     []entries.Entry // visibles, ordenadas y numeradas
	shown    []entries.Entry // list filtrada
	cursor   int             // índice en shown
	mode     mode
	filter   string
	pending  string // "d" o "g" esperando la segunda tecla
	digit    string // primer dígito esperando el segundo
	seq      int    // invalida timeouts viejos
	register string // clave cortada con dd
	frame    int
	width    int
	height   int
	offset   int // primera fila visible
	err      error
	quitting bool
}

func New(d Deps) Model {
	m := Model{d: d, width: 80, height: 24}
	m.reload()
	return m
}

func (m Model) Init() tea.Cmd { return tea.Batch(tick(), spin()) }

func tick() tea.Cmd {
	return tea.Tick(refreshEvery, func(time.Time) tea.Msg { return tickMsg{} })
}

func spin() tea.Cmd {
	return tea.Tick(spinEvery, func(time.Time) tea.Msg { return spinMsg{} })
}

func (m *Model) after(d time.Duration) tea.Cmd {
	m.seq++
	s := m.seq
	return tea.Tick(d, func(time.Time) tea.Msg { return timeoutMsg{seq: s} })
}

func (m Model) Update(msg tea.Msg) (tea.Model, tea.Cmd) {
	next, cmd := m.update(msg)
	next.scroll()
	return next, cmd
}

func (m Model) update(msg tea.Msg) (Model, tea.Cmd) {
	switch msg := msg.(type) {
	case tea.WindowSizeMsg:
		m.width, m.height = msg.Width, msg.Height
	case tickMsg:
		m.reload()
		return m, tick()
	case spinMsg:
		m.frame++
		return m, spin()
	case timeoutMsg:
		if msg.seq != m.seq {
			return m, nil
		}
		m.pending = ""
		if d := m.digit; d != "" {
			m.digit = ""
			return m.jump(d)
		}
	case tea.KeyMsg:
		if m.mode == filtering {
			return m.filterKey(msg)
		}
		return m.normalKey(msg)
	}
	return m, nil
}

func (m Model) normalKey(k tea.KeyMsg) (Model, tea.Cmd) {
	key := k.String()
	if d := m.digit; d != "" {
		m.digit = ""
		if isDigit(key) {
			return m.jump(d + key)
		}
		return m.jump(d)
	}
	if p := m.pending; p != "" {
		m.pending = ""
		switch p + key {
		case "dd":
			m.hide()
			return m, nil
		case "gg":
			m.cursor = 0
			return m, nil
		}
		// cualquier otra tecla cancela la secuencia y se procesa normal
	}
	switch key {
	case "q", "ctrl+c":
		return m.quit()
	case "esc":
		if m.filter != "" {
			m.setFilter("")
			return m, nil
		}
		return m.quit()
	case "j", "down":
		m.move(1)
	case "k", "up":
		m.move(-1)
	case "G":
		m.cursor = len(m.shown) - 1
		m.clamp()
	case "d", "g":
		m.pending = key
		return m, m.after(seqTimeout)
	case "p":
		m.paste(true)
	case "P":
		m.paste(false)
	case "U":
		m.restoreAll()
	case "/":
		m.mode = filtering
	case "enter":
		return m.open(m.selected())
	default:
		if isDigit(key) && key != "0" {
			n, _ := strconv.Atoi(key)
			if len(m.list) >= 10 && n*10 <= len(m.list) {
				m.digit = key
				return m, m.after(digitTimeout)
			}
			return m.jump(key)
		}
	}
	return m, nil
}

func (m Model) filterKey(k tea.KeyMsg) (Model, tea.Cmd) {
	switch k.Type {
	case tea.KeyCtrlC:
		return m.quit()
	case tea.KeyEsc:
		m.mode = normal
		m.setFilter("")
	case tea.KeyEnter:
		m.mode = normal
	case tea.KeyBackspace:
		if r := []rune(m.filter); len(r) > 0 {
			m.setFilter(string(r[:len(r)-1]))
		}
	case tea.KeyCtrlN, tea.KeyDown:
		m.move(1)
	case tea.KeyCtrlP, tea.KeyUp:
		m.move(-1)
	case tea.KeySpace:
		m.setFilter(m.filter + " ")
	case tea.KeyRunes:
		m.setFilter(m.filter + string(k.Runes))
	}
	return m, nil
}

func isDigit(s string) bool { return len(s) == 1 && s[0] >= '0' && s[0] <= '9' }

func (m Model) quit() (Model, tea.Cmd) {
	m.quitting = true
	return m, tea.Quit
}

// jump usa siempre el número global, no la posición filtrada.
func (m Model) jump(num string) (Model, tea.Cmd) {
	n, err := strconv.Atoi(num)
	if err != nil {
		return m, nil
	}
	for i := range m.list {
		if m.list[i].Num == n {
			return m.open(&m.list[i])
		}
	}
	return m, nil
}

func (m Model) open(e *entries.Entry) (Model, tea.Cmd) {
	if e == nil {
		return m, nil
	}
	if err := m.d.Switch(e.Pane); err != nil {
		m.err = err
		return m, nil
	}
	return m.quit()
}

func (m *Model) reload() {
	live, err := m.d.Load()
	if err != nil {
		m.err = err // se mantiene la última lista buena
		return
	}
	m.err = nil
	m.live = live
	m.relist()
}

func (m *Model) relist() {
	key := m.currentKey()
	m.list = entries.Arrange(m.live, m.d.Order.Visible(entries.Keys(m.live)))
	m.applyFilter()
	m.placeCursor(key)
}

// applyFilter mantiene el orden de la lista (no el del score) para que los
// encabezados sigan teniendo sentido.
func (m *Model) applyFilter() {
	if m.filter == "" {
		m.shown = m.list
		return
	}
	src := make([]string, len(m.list))
	for i, e := range m.list {
		src[i] = e.Pane.Session + " " + e.Folder + " " + e.Title
	}
	matches := fuzzy.Find(m.filter, src)
	sort.Slice(matches, func(i, j int) bool { return matches[i].Index < matches[j].Index })
	m.shown = make([]entries.Entry, 0, len(matches))
	for _, mt := range matches {
		m.shown = append(m.shown, m.list[mt.Index])
	}
}

func (m *Model) setFilter(f string) {
	key := m.currentKey()
	m.filter = f
	m.applyFilter()
	m.placeCursor(key)
}

// placeCursor vuelve a la misma entrada; si ya no está, el índice queda igual
// (la siguiente ocupa su lugar) o baja a la última.
func (m *Model) placeCursor(key string) {
	for i := range m.shown {
		if m.shown[i].Key == key {
			m.cursor = i
			return
		}
	}
	m.clamp()
}

func (m *Model) clamp() {
	if m.cursor >= len(m.shown) {
		m.cursor = len(m.shown) - 1
	}
	if m.cursor < 0 {
		m.cursor = 0
	}
}

func (m *Model) move(d int) {
	m.cursor += d
	m.clamp()
}

func (m *Model) selected() *entries.Entry {
	if m.cursor >= 0 && m.cursor < len(m.shown) {
		return &m.shown[m.cursor]
	}
	return nil
}

func (m *Model) currentKey() string {
	if e := m.selected(); e != nil {
		return e.Key
	}
	return ""
}

func (m *Model) hide() {
	e := m.selected()
	if e == nil {
		return
	}
	key := e.Key
	m.d.Order.Hide(entries.Keys(m.live), key)
	m.register = key
	m.save()
	m.relist()
}

func (m *Model) paste(below bool) {
	if m.register == "" {
		return
	}
	key := m.register
	m.register = ""
	m.d.Order.Paste(entries.Keys(m.live), key, m.currentKey(), below)
	m.save()
	m.relist()
	m.placeCursor(key)
}

func (m *Model) restoreAll() {
	m.d.Order.RestoreAll(entries.Keys(m.live))
	m.save()
	m.relist()
}

func (m *Model) save() {
	if err := m.d.SaveOrder(); err != nil {
		m.err = err
	}
}

// listHeight: alto total menos título, separador, detalle y ayuda.
func (m *Model) listHeight() int {
	if h := m.height - 4; h > 0 {
		return h
	}
	return 1
}

// scroll ajusta offset para que el cursor (y, si se puede, su encabezado)
// quede visible.
func (m *Model) scroll() {
	rows := buildRows(m.shown)
	cur := -1
	for i, r := range rows {
		if r.entry == m.cursor {
			cur = i
			break
		}
	}
	if cur < 0 {
		m.offset = 0
		return
	}
	top := cur
	if cur > 0 && rows[cur-1].entry < 0 {
		top = cur - 1
	}
	if top < m.offset {
		m.offset = top
	}
	if h := m.listHeight(); cur >= m.offset+h {
		m.offset = cur - h + 1
	}
	if m.offset < 0 {
		m.offset = 0
	}
}

package tui

import (
	"fmt"
	"strings"

	"github.com/charmbracelet/lipgloss"

	"ccm/internal/entries"
	"ccm/internal/state"
)

const helpText = "j/k mover · ⏎ ir · / filtrar · dd ocultar · p pegar · U restaurar · q salir"

const folderWidth = 16

var (
	styleTitle  = lipgloss.NewStyle().Bold(true).Foreground(lipgloss.Color("#7aa2f7"))
	styleHeader = lipgloss.NewStyle().Foreground(lipgloss.Color("#7aa2f7"))
	styleDim    = lipgloss.NewStyle().Foreground(lipgloss.Color("#565f89"))
	styleSel    = lipgloss.NewStyle().Bold(true).Foreground(lipgloss.Color("#c0caf5"))
	styleErr    = lipgloss.NewStyle().Foreground(lipgloss.Color("#f7768e"))
)

func (m Model) View() string {
	if m.quitting {
		return ""
	}
	var b strings.Builder
	head := " ccm"
	if m.mode == filtering {
		head += "   /" + m.filter + "▏"
	} else if m.filter != "" {
		head += "   /" + m.filter
	}
	b.WriteString(styleTitle.Render(fit(head, m.width)) + "\n")

	if len(m.list) == 0 {
		b.WriteString(styleDim.Render(fit("  sin sesiones de Claude Code", m.width)) + "\n")
		b.WriteString(styleDim.Render(fit(" q salir", m.width)))
		return b.String()
	}

	rows := buildRows(m.shown)
	h := m.listHeight()
	n := 0
	for i := m.offset; i < len(rows) && n < h; i++ {
		r := rows[i]
		if r.entry < 0 {
			b.WriteString(styleHeader.Render(fit(" "+r.header, m.width)) + "\n")
		} else {
			b.WriteString(m.renderEntry(m.shown[r.entry], r.entry == m.cursor) + "\n")
		}
		n++
	}
	for ; n < h; n++ {
		b.WriteString("\n")
	}
	b.WriteString(styleDim.Render(strings.Repeat("─", max(m.width, 1))) + "\n")
	b.WriteString(m.detailLine() + "\n")
	b.WriteString(styleDim.Render(fit(" "+helpText, m.width)))
	return b.String()
}

// Fila: marca(2) + número(3) + indicador(1) + 2 + carpeta + 2 + título.
func (m Model) renderEntry(e entries.Entry, selected bool) string {
	mark := "  "
	if selected {
		mark = styleTitle.Render("› ")
	}
	titleW := m.width - (2 + 3 + 1 + 2 + folderWidth + 2)
	text := fit(e.Folder, folderWidth) + "  " + fit(e.Title, titleW)
	if selected {
		text = styleSel.Render(text)
	}
	return mark + fmt.Sprintf("%2d ", e.Num) + indicator(e.State, m.frame) + "  " + text
}

func (m Model) detailLine() string {
	if m.err != nil {
		return styleErr.Render(fit(" error: "+m.err.Error(), m.width))
	}
	e := m.selected()
	if e == nil {
		return ""
	}
	title := e.Detail
	if title == "" {
		title = e.Title
	}
	var parts []string
	if title != "" {
		parts = append(parts, title)
	}
	parts = append(parts, stateLabel(e.State))
	if e.State != state.Unknown && !e.Since.IsZero() {
		parts = append(parts, humanSince(m.d.Now().Sub(e.Since)))
	}
	return styleDim.Render(fit(" "+strings.Join(parts, " · "), m.width))
}

// ccm: selector de sesiones de Claude Code dentro de tmux.
//
//	ccm               abre la TUI (pensado para display-popup)
//	ccm hook <evento> lo llaman los hooks de Claude Code
//	ccm seen          lo llaman los hooks de tmux al cambiar de window
package main

import (
	"fmt"
	"io"
	"os"
	"path/filepath"
	"time"

	tea "github.com/charmbracelet/bubbletea"

	"ccm/internal/entries"
	"ccm/internal/hook"
	"ccm/internal/order"
	"ccm/internal/paths"
	"ccm/internal/state"
	"ccm/internal/tmux"
	"ccm/internal/transcript"
	"ccm/internal/tui"
)

func main() {
	os.Exit(run(os.Args[1:], os.Stdin, os.Stdout, os.Stderr))
}

func run(args []string, stdin io.Reader, stdout, stderr io.Writer) int {
	if len(args) == 0 {
		return runTUI(stderr)
	}
	switch args[0] {
	case "hook":
		if len(args) < 2 {
			logf("hook sin evento")
			return 0
		}
		runHook(args[1], stdin)
		return 0
	case "seen":
		runSeen()
		return 0
	}
	fmt.Fprintln(stderr, "uso: ccm [hook <evento> | seen]")
	return 2
}

// logf nunca escribe a stdout/stderr: Claude Code lee el stdout del hook.
func logf(format string, a ...any) {
	p := paths.LogPath()
	_ = os.MkdirAll(filepath.Dir(p), 0o755)
	f, err := os.OpenFile(p, os.O_APPEND|os.O_CREATE|os.O_WRONLY, 0o644)
	if err != nil {
		return
	}
	defer f.Close()
	fmt.Fprintf(f, "%s %s\n", time.Now().Format(time.RFC3339), fmt.Sprintf(format, a...))
}

func runHook(event string, stdin io.Reader) {
	defer func() {
		if r := recover(); r != nil {
			logf("hook %s: panic: %v", event, r)
		}
	}()
	d := hook.Deps{
		Store:  state.Store{Dir: paths.PanesDir()},
		PaneID: os.Getenv("TMUX_PANE"),
		Now:    time.Now,
		PaneActive: func(id string) (bool, error) {
			bin, err := tmux.Find()
			if err != nil {
				return false, err
			}
			return tmux.Exec{Bin: bin}.PaneActive(id)
		},
	}
	if err := hook.Run(event, stdin, d); err != nil {
		logf("hook %s: %v", event, err)
	}
}

func runSeen() {
	bin, err := tmux.Find()
	if err != nil {
		logf("seen: %v", err)
		return
	}
	if err := hook.Seen(tmux.Exec{Bin: bin}, state.Store{Dir: paths.PanesDir()}, time.Now()); err != nil {
		logf("seen: %v", err)
	}
}

func runTUI(stderr io.Writer) int {
	if os.Getenv("TMUX") == "" {
		fmt.Fprintln(stderr, "ccm: hay que correrlo dentro de tmux")
		return 1
	}
	bin, err := tmux.Find()
	if err != nil {
		fmt.Fprintln(stderr, "ccm:", err)
		return 1
	}
	tm := tmux.Exec{Bin: bin}
	store := state.Store{Dir: paths.PanesDir()}
	titles := transcript.NewCache(paths.TitlesDir())
	ord, err := order.Load(paths.OrderPath())
	if err != nil {
		logf("%v", err) // orden por defecto; se reescribe en el próximo cambio
	}

	purged := false
	load := func() ([]entries.Entry, error) {
		panes, err := tm.ListPanes()
		if err != nil {
			return nil, err
		}
		states, err := store.All()
		if err != nil {
			return nil, err
		}
		if !purged {
			entries.Purge(store, panes, states)
			purged = true
		}
		return entries.Collect(panes, states, titles.Get), nil
	}

	m := tui.New(tui.Deps{
		Load:      load,
		Order:     ord,
		SaveOrder: func() error { return ord.Save(paths.OrderPath()) },
		Switch:    tm.Switch,
		Now:       time.Now,
	})
	if _, err := tea.NewProgram(m, tea.WithAltScreen()).Run(); err != nil {
		fmt.Fprintln(stderr, "ccm:", err)
		return 1
	}
	return 0
}
```
