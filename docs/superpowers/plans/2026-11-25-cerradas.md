# Sesiones cerradas — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `c` en el popup de ccm lista las sesiones de Claude Code cerradas, con buscador fuzzy, y `Enter` las retoma en una window nueva de tmux.

**Architecture:** Un paquete nuevo `closed` persiste un registro (`closed.json`) que alimentan `hook end` y `Purge`; `hook start` saca de ahí lo que se retoma. La TUI suma un modo `closedView` con su propio archivo; retomar es `closed.Resume` sobre una interfaz chica de tmux.

**Tech Stack:** Go 1.24, bubbletea, lipgloss, `sahilm/fuzzy` (ya en go.mod). Sin dependencias nuevas.

**Spec:** `docs/superpowers/specs/2026-11-25-cerradas-design.md`

## Global Constraints

- `ccm hook` nunca escribe a stdout/stderr y siempre sale con 0; errores van a `logf`.
- Registro en `paths.StateDir()/closed.json`; tope 50; sin duplicados por `session_id`; más reciente primero.
- No se registran sesiones sin `session_id` o sin `last_prompt`.
- Escrituras con `fsutil.WriteFileAtomic`. Archivo corrupto = lista vacía, sin error visible.
- Comentarios: solo el porqué no deducible; en español, como el resto del repo.
- Tests con `t.TempDir()` y fakes, sin tmux real.
- No commitear: el dueño del repo commitea a pedido. Los pasos "Commit" quedan pendientes de su OK.
- Verificación de cada task: `go test ./... && go vet ./...` en verde.

## Review Focus

1. Varias sesiones cierran a la vez (`tmux kill-session`): no se pierde ninguna entrada. → Task 1 (lock).
2. Retomar y cerrar sin escribir nada: la sesión sigue en la lista con su último prompt. → Task 2.
3. El `cwd` o la sesión de tmux ya no existen al retomar: error visible / cae a la sesión actual, nunca una window rota. → Task 4.
4. `closed.json` editado a mano con un `session_id` raro: no se inyecta en el shell. → Task 4.
5. Query sin resultados, lista vacía y popup angosto en la vista: no hay panic ni líneas más anchas que `width`. → Task 5.

Comportamiento en `hook.Run`:

Un error de `Add` no impide el `Delete` (se devuelve el del `Add` para el log).
- `Closed.Path == ""` desactiva todo lo anterior (así los tests existentes no cambian).

En `main.go`, `runHook` arma `Closed: closed.Store{Path: paths.ClosedPath()}`, `PaneLoc` con `tmux.Exec` y `Labels` cargando `order.Load(paths.OrderPath())`.

```go
// internal/tmux
func (e Exec) HasSession(name string) bool                         // has-session -t =name
func (e Exec) CurrentSession() (string, error)                     // display-message -p #{session_name}
func (e Exec) NewWindow(session, cwd string) (PaneInfo, error)     // new-window -d -P -F listFormat -t "=<session>:" -c <cwd>

type Tmux interface {
	HasSession(name string) bool
	CurrentSession() (string, error)
	NewWindow(session, cwd string) (tmux.PaneInfo, error)
	SendLine(paneID, line string) error
	Switch(p tmux.PaneInfo) error
}

var ErrBadSession = errors.New("session id inválido")

func Resume(c Session, t Tmux) (tmux.PaneInfo, error)
```

`Resume`, en orden: valida `c.SessionID` contra `^[0-9A-Za-z_-]+$` (si no, `ErrBadSession`); `os.Stat(c.Cwd)` debe ser directorio (si no, error `"la carpeta ya no existe: <cwd>"`); sesión destino = `c.TmuxSession` si `HasSession`, si no `CurrentSession()`; `NewWindow`; `SendLine(pane, "claude --resume "+c.SessionID)`; `Switch`. Devuelve el `PaneInfo` de la window nueva.

Se abre un shell y se le tipea el comando (en vez de pasar `claude` como comando de la window) para que al salir de Claude quede el shell, igual que una sesión abierta a mano, y se use el PATH interactivo.

### Task 5: vista "Cerradas" con buscador + README

**Files:**
- Create: `internal/tui/closed.go`, `internal/tui/closed_test.go`
- Modify: `internal/tui/model.go` (modo, tecla `c`, despacho), `internal/tui/view.go` (`View`, `helpLine`, `normalHelp`), `cmd/ccm/main.go`, `README.md`

**Interfaces:**
- Consumes: `closed.Session`, `closed.Store.List`, `closed.Resume`, `transcript.Cache.Get`, `order.Key`, `order.Store.SetAlias/SetStatus`.
- Produces — campos nuevos en `tui.Deps` (nil = la tecla `c` no hace nada):

```go
Closed func() []closed.Session
Titles func(sessionID, path string) transcript.Titles
Resume func(closed.Session) (tmux.PaneInfo, error)
```

Modelo: modo nuevo `closedView`; estado propio en `Model` (`closedAll`, `closedShown` con los índices que matchearon, `query`, `ccursor`, `coffset`).

Comportamiento:
- `c` en modo normal (sin secuencia pendiente) carga `Closed()`, resuelve el título de cada una (`Titles(...).Row()`; vacío → `LastPrompt`), deja `query` vacía y entra a `closedView`. La lista se carga una vez al entrar; el `tickMsg` no la recarga.
- Teclas en `closedView`: runas y espacio agregan a `query`; backspace borra; `↑`/`C-p`/`C-k` y `↓`/`C-n`/`C-j` mueven; `Enter` retoma; `Esc` limpia la query, y con query vacía vuelve a `normal`; `C-c` cierra.
- Filtro: `fuzzy.Find(query, haystacks)`, con haystack = `TmuxSession + " " + loc + " " + título + " " + Status + " " + LastPrompt`, donde `loc` = `Alias` o, si está vacío, `filepath.Base(Cwd)`. Sin query: orden de `Closed()`. Con query: orden por score (el que devuelve `fuzzy.Find`). El cursor vuelve a 0 cada vez que cambia la query.
- Render (alto disponible = `height - headerLines() - 4`, igual que la lista normal; una fila por entrada, sin encabezados de grupo):
  - línea 1 (donde hoy van los títulos de columna): ` > <query>▏` con `styleSel`; con query vacía, `styleDim` y el texto ` > escribí para buscar`.
  - filas: marca de selección como en `renderEntry` + `humanSince(Now-ClosedAt)` (ancho 9) + sesión de tmux + `loc` + título. Los caracteres que matchearon en sesión/loc/título van con `styleAccent`; el resto como en la lista normal (`styleSel` + `selBg` en la seleccionada). Cada línea truncada a `width`.
  - sin entradas: `  todavía no hay sesiones cerradas`; con query sin resultados: `  sin resultados`.
  - detalle: `<LastPrompt> · cerrada <humanSince>` (más el status adelante si tiene, como en `detailLine`); `m.err` tiene prioridad como hoy.
  - header: el mismo, con el resumen reemplazado por `Cerradas · <n>`.
  - ayuda: `closedHelp = {"", "escribí para buscar"}, {"↑/↓", "mover"}, {"⏎", "retomar"}, {"esc", "volver"}`.
- `Enter`: `Resume(sel)`. Error → `m.err`, se queda en la vista. OK → si la entrada tenía `Alias`/`Status`, `Order.SetAlias/SetStatus(order.Key(p.Session, p.Window, p.Pane, p.Path), …)` + `SaveOrder`; después `quit`.
- `normalHelp` suma `{"c", "cerradas"}` antes de `{"q", "salir"}`.

`main.go`: `Closed: closed.Store{Path: paths.ClosedPath()}.List`, `Titles: titles.Get`, `Resume: func(c) { return closed.Resume(c, tm) }`.

README: fila `c` en la tabla de teclas ("ver sesiones cerradas; escribí para buscar, `Enter` la retoma en una window nueva") y un bullet en "Cómo funciona" ("**Cerradas:** `hook end` y la limpieza de panes muertos las anotan en `~/.local/state/ccm/closed.json` (últimas 50)").
